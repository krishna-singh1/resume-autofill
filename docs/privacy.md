# Resume Autofill — Privacy Policy

_Last updated: 23 September 2026_

Resume Autofill is a browser extension that fills job application forms using
information you save in it. This policy explains what that information is,
where it is kept, and what the extension does with it.

## The short version

- Everything you enter stays **on your device**, in the browser's local
  extension storage.
- The extension **sends nothing to any server**. There is no account, no
  cloud sync, no analytics, no advertising, and no tracking.
- The developer **cannot see your data**, because it never leaves your browser.

## What the extension stores

When you use it, the extension saves the following in `chrome.storage.local`:

| Data | Where it comes from |
| --- | --- |
| Profile: name, email, phone, address, links, work history, education, skills, projects | Typed by you, or read from a resume file you choose to import |
| Application answers: salary expectation, start date, notice period, relocation, work authorisation and sponsorship | Typed by you |
| Voluntary self-identification answers (gender, ethnicity, veteran and disability status) | Only if you choose to fill them in. Filling these into forms is **off by default** |
| Resume and cover-letter files | Files you choose to upload, kept so they can be attached to application forms |
| Remembered answers | Answers you confirm the extension should remember, together with the question text and the websites where each was used |
| Settings | Your choices on the extension's settings page |

## How the data is used

The data is used for one purpose: **filling in forms that you ask it to
fill.** Specifically:

- When you click **Fill this page** or press the keyboard shortcut, the
  extension reads the form on the current page and writes your saved details
  into matching fields. It does not run on pages until you ask it to.
- When you import a resume, the file is read **inside your browser** to extract
  text. It is not uploaded anywhere.
- When you build a resume, it is rendered locally from your profile. Printing
  or saving it as a PDF uses your browser's own print dialog.

The extension never submits a form. You review what it filled and submit it
yourself.

## What is shared

Nothing is shared by the extension. The only time your information leaves your
device is when **you** submit an application form on a website, exactly as if
you had typed the details yourself. What that website does with it is covered
by that website's own privacy policy.

The extension contains no third-party analytics or advertising code. The only
third-party code it includes is Mozilla's pdf.js library, bundled inside the
extension and used offline to read PDF files.

## Permissions and why they are needed

| Permission | Reason |
| --- | --- |
| Storage, unlimited storage | To keep your profile and resume file on your device |
| Scripting, active tab | To fill the form on the current page when you ask |
| Access to websites | Application forms are often embedded from another site (for example a Greenhouse form inside a company's careers page); this lets the extension reach those embedded forms. It is only used when you trigger a fill |

## Your control over your data

- **Edit or delete** any field or remembered answer on the extension's profile
  page.
- **Export** everything to a file with the Export button. That file contains
  your personal information, so store it carefully.
- **Delete everything** with the Clear all button, or by removing the extension
  from your browser, which erases its local storage.

## Children

The extension is intended for people applying for jobs and is not directed at
children under 13.
